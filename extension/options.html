Phone unlock

Get a 6-digit code from an authenticator app (Google Authenticator, Microsoft Authenticator, 2FAS, Authy and others). Type it to unlock, or text it to whoever is at the computer. Each code works once and expires after 30 seconds, so the real password stays secret.
